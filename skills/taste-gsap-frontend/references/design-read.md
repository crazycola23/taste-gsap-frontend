# Design Read

Record decisions that affect this task, briefly. Existing products supply their
system; a fresh website uses `start.mjs` and `assets/layout/deal.mjs`.

```text
Kind and scope: business kind, website/app/component, new/restyle/motion-only.
Reader's job: what the first screen must explain or let them do.
System: preserved or dealt palette, type, hero, spacing and image treatment.
Material: actual photographs/product UI/facts; missing assets and honest stand-ins.
Motion: mode + ambition, what changes, what that change explains.
```

For each moving region record purpose, owner, trigger, desktop behavior, phone
fallback and reduced-motion state. Name the kit, CSS or GSAP owner explicitly.
One line per region is enough. Keep these notes out of product copy.
