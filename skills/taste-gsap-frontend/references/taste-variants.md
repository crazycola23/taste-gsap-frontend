# Other taste skills

This skill combines the complete tasteskill 2.5.1 website kit with GSAP integration
and a scoped app-screen route. Do not stack another design workflow on an active run.

Classic variants such as `gpt-taste`, `minimalist-ui`, `industrial-brutalist-ui`
and `high-end-visual-design` live at
https://github.com/Leonxlnx/taste-skill-classics.
Image-reference and generation workflows live at
https://github.com/Leonxlnx/imagegen-skills.

Use a named variant only when requested and available; otherwise explain the missing
variant and continue within this skill's capabilities. The user's scope, supplied
brand/content and explicit Static request take priority over house-style defaults.
